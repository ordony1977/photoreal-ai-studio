# Grok Image Studio

## التشغيل
1. ثبّت Node.js 18 أو أحدث.
2. افتح الطرفية داخل مجلد المشروع.
3. شغّل `npm start`.
4. افتح `http://localhost:3000` في المتصفح.
5. أدخل مفتاح xAI API الخاص بك داخل الموقع (لا تشاركه مع أحد).

لا تحتاج تثبيت أي حزم npm. المشروع للاستخدام المحلي فقط، والخادم يستمع إلى 127.0.0.1.

## ملاحظات
- يرسل الطلبات إلى واجهة xAI Images عبر خادم محلي، وليس مباشرة من المتصفح.
- يعتمد نجاح تعديل الصور ونسب الأبعاد وتوليد عدة صور على دعم API والموديل والحساب، وقد تحتاج تعديل أسماء الموديلات أو معلمات الطلب لتوافق التوثيق الحالي.
- خيار حفظ المفتاح في المتصفح ليس تخزينًا آمنًا للأسرار؛ لا تفعّله على جهاز مشترك.
- حفظ سجل الصور في localStorage محدود السعة؛ نزّل الصور المهمة.
- لا تنشر الخادم كما هو على الإنترنت: يحتاج مصادقة وحماية إضافية قبل النشر.
